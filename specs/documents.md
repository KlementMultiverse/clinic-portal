# Documents — S3 Storage, Presigned URLs, Lambda Summarization

<system-reminder>
1. S3 keys MUST be namespaced by tenant: `{tenant_schema_name}/{uuid}/{original_filename}` — this prevents cross-tenant file access even if someone guesses a key.
2. Presigned URLs MUST expire after 15 minutes (900 seconds) — NEVER serve S3 files directly or use longer expiry.
3. NEVER proxy file uploads/downloads through Django — always use presigned URLs so the browser talks directly to S3.
4. Lambda invocation for summarization uses `boto3.client("lambda").invoke()` with `InvocationType="RequestResponse"` — NEVER call OpenAI directly from Django.
5. When deleting a document, delete BOTH the S3 object AND the database row. If S3 deletion fails, log the error but still delete the DB row (orphaned S3 objects are cheaper than orphaned DB rows pointing to missing files).
</system-reminder>

## Goal

Authenticated tenant members can upload documents to S3 via presigned URLs, register uploaded documents in the database, list documents, download documents via presigned URLs, request LLM-powered summaries via AWS Lambda, and delete documents. All files are isolated per tenant via S3 key namespacing.

## Definitions

- **Document**: Database record for an uploaded file. Fields: `id`, `name` (CharField, max 300 -- original filename), `s3_key` (CharField, max 500 -- full S3 object path), `content_type` (CharField, max 100 -- MIME type), `size_bytes` (IntegerField), `summary` (TextField, blank -- LLM-generated), `workflow` (FK to Workflow, nullable), `task` (FK to Task, nullable), `uploaded_by` (FK to User), `created_at` (auto_now_add).
- **Presigned upload URL**: A URL + form fields generated by `boto3 s3.generate_presigned_post()` that allows the browser to POST a file directly to S3 without AWS credentials.
- **Presigned download URL**: A URL generated by `boto3 s3.generate_presigned_url("get_object", ...)` that allows the browser to GET the file directly from S3.
- **S3 key format**: `{tenant_schema_name}/{uuid4}/{original_filename}` -- ensures uniqueness and tenant isolation.
- **Upload flow**: (1) Frontend calls `POST /api/documents/upload-url` with filename + content_type. (2) Backend generates presigned POST and S3 key, returns both. (3) Frontend uploads directly to S3. (4) Frontend calls `POST /api/documents/` with s3_key, name, content_type, size_bytes to register in DB.
- **Summarize**: Calls Lambda with `{"text": "<document text>", "task_type": "summarize_document"}`, receives `{"summary": "..."}`, stores summary on the Document record.

## Plan

1. Create `apps/documents/__init__.py` (empty) and `apps/documents/models.py` with the `Document` model.
2. Verify `apps.documents` is in `TENANT_APPS` in `config/settings.py`.
3. Create `apps/documents/schemas.py` with Django Ninja schemas: `UploadUrlIn` (filename, content_type), `UploadUrlOut` (url, fields dict, s3_key), `DocumentIn` (name, s3_key, content_type, size_bytes, workflow_id optional, task_id optional), `DocumentOut` (id, name, s3_key, content_type, size_bytes, summary, workflow_id, task_id, uploaded_by_name, created_at), `DownloadUrlOut` (url), `SummarizeOut` (summary).
4. Create `apps/documents/services.py` with:
   a. `generate_upload_url(tenant_schema_name, filename, content_type) -> dict` — generates S3 key as `{schema}/{uuid4}/{filename}`, calls `s3_client.generate_presigned_post()` with 15-min expiry and conditions (content-type match, max 50MB size), returns `{"url": ..., "fields": ..., "s3_key": ...}`.
   b. `generate_download_url(s3_key) -> str` — calls `s3_client.generate_presigned_url("get_object", ...)` with 15-min expiry.
   c. `delete_s3_object(s3_key) -> bool` — calls `s3_client.delete_object()`, returns True on success, logs and returns False on failure.
   d. `invoke_summarize(text: str) -> str` — calls Lambda with `task_type="summarize_document"`, returns summary string.
5. Create `apps/documents/api.py` with a Django Ninja Router containing 6 endpoints: list, upload-url, create (register), download-url, summarize, delete.
6. Wire the router into `config/urls.py` (tenant URL config) under `/api/documents/`.
7. Write tests in `apps/documents/tests.py`. Mock boto3 calls in tests.
8. Run `uv run python manage.py migrate_schemas --tenant`.
9. Run `black . && ruff check . --fix`, then `uv run python manage.py test`.

## Edge Cases

- Filename sanitization: strip path components (no `../../etc/passwd`), replace spaces with underscores, limit to 255 characters. Keep the original name in the `name` DB field but sanitize the S3 key component.
- Content type validation: only allow common document types (pdf, doc, docx, txt, png, jpg, jpeg, csv, xlsx). Reject unknown MIME types with 400.
- Size limit: presigned POST conditions should enforce max 50MB. The `size_bytes` field in the register endpoint is informational (actual size is enforced by S3 presigned conditions).
- S3 key in the register endpoint (`POST /api/documents/`) MUST start with the current tenant's `schema_name` prefix. If it does not, return 403 (prevents a user from registering a document from another tenant's namespace).
- If S3 delete fails during document deletion, log the error at WARNING level but still delete the DB row. Return 200 to the client.
- The summarize endpoint requires the document to have text content. For non-text documents (images, spreadsheets), return 400 with "Document type not supported for summarization".
- Duplicate s3_key in the register endpoint should be rejected with 409 (unique constraint on s3_key).
- Lambda timeout: 30-second timeout on the boto3 invocation. Return 502 on timeout.

## Out of Scope

- File preview or rendering in the browser
- Document versioning (overwriting a document creates a new record)
- Folder/directory structure within a tenant
- Full-text search across document contents
- Batch upload or zip file extraction
- Document sharing across tenants
- Virus scanning on upload
